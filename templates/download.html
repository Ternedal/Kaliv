Hardware og netværk.

Ved lokal brug kører din rig modellen; telefonen forbinder over lokalnettet. Disse krav er adskilt fra kravene til selve appen.

KravLokal opsætning
StyresystemModelRig: Windows eller Linux. Udgivne klienter: Windows x64 med Java {{ downloads.windows.java_version }} eller Android {{ downloads.android.minimum_version }}+.
RAMAfhænger af model og aktive funktioner. Et afprøvet minimum er endnu ikke fastlagt.
GPU / VRAMEt dokumenteret eksempel er qwen3:14b på RTX 3060 med 12 GB VRAM. Det er en afprøvet modelkonfiguration, ikke et minimum for alle funktioner. Hele opsætningen er ikke kvalificeret til ren CPU-drift.
DiskDer skal være plads til modeller, installation og dine data. Et samlet minimum er endnu ikke fastlagt; modelvalget ændrer downloadstørrelsen.
NetværkBrug samme betroede LAN eller Wi-Fi til telefon og rig. Riggen skal være tændt og kunne nås. Internet bruges til downloads, opdateringer og valgfri cloud-brug.

Første gang: start din rig.

Trinene her beskriver Windows-serveren. Til Linux-installation som tjeneste: brug den fulde installationsvejledning.

  1. Installér Ollama til Windows. Vælg og hent en model, der passer til din hardware. Kommandoerne her bruger qwen3:8b som eksempel, ikke som et løfte om minimumshardware.

    Hent Ollama til Windows 
    ollama pull qwen3:8b
ollama pull nomic-embed-text

  2. Hent Windows-serveren og workeren fra denne udgivelse. Gem begge i C:\Kaliv. De færdige programmer kræver ikke en Python- eller Go-installation.

    Hent Windows-server Hent Windows-worker

  3. Åbn to PowerShell-vinduer. Start workeren i det første vindue, og lad den køre:

    Set-Location C:\Kaliv
$env:MODELRIG_GEN_MODEL = "qwen3:8b"
.\modelrig-worker-windows-x64.exe

    Start serveren i det andet vindue. MODELRIG_HOST gør den tilgængelig på dit betroede lokalnet:

    Set-Location C:\Kaliv
$env:MODELRIG_HOST = "0.0.0.0"
.\modelrig-server-windows-x64.exe

  4. Mens serveren kører, åbn et tredje PowerShell-vindue, og opret en parringskode:

    Set-Location C:\Kaliv
.\modelrig-server-windows-x64.exe -pair

  5. Installér en klient med vejledningen nedenfor. På selve riggen forbindes til http://localhost:8080. På telefonen bruges http://RIGGENS-LAN-IP:8080 på samme netværk; indtast parringskoden, og vælg din hentede model. Send en kort tekstbesked, før du prøver stemme.

Installér og start på Windows

Anbefalet Java-build: Eclipse Temurin JDK {{ downloads.windows.java_version }} LTS, Windows x64, HotSpot, MSI-installation. Behold installationens Add to PATH-valg, og åbn derefter et nyt PowerShell-vindue.

Hent Temurin Java {{ downloads.windows.java_version }} til Windows x64

Hent klienten ovenfor. Åbn PowerShell i downloadmappen, og kør:

java -jar ".\{{ downloads.windows.filename }}"

Brug klientens indstillinger til at forbinde til din rig. Den fulde desktopvejledning beskriver forbindelsesmulighederne.

Installér og opdatér på Android
  1. Kontrollér, at telefonen har Android {{ downloads.android.minimum_version }} eller nyere. Hent APK-filen ovenfor, og åbn den fra browseren eller appen Filer.
  2. Hvis Android spørger, åbn Indstillinger → Installér ukendte apps, og tillad den browser eller filapp, du brugte. Gå tilbage til APK-filen, og bekræft installationen. Ordlyden varierer mellem telefoner.
  3. Åbn Kaliv, indtast riggens serveradresse og parringskode, og vælg en model. Brug samme lokalnet som riggen.

Appen tilbyder nye versioner. Du starter selv opdateringen og bekræfter installationen i Android; opdateringer installeres ikke i stilhed.

Kontrollér din download

Sammenlign filens SHA-256 med checksumlisten fra den samme udgivelse, før du åbner filen.

Vis checksumvejledning
  1. Hent SHA256SUMS.txt til v{{ latest_release.version }}

  2. Åbn PowerShell i downloadmappen, og erstat FILNAVN med det præcise filnavn.

    Get-FileHash -LiteralPath ".\FILNAVN" -Algorithm SHA256

  3. Sammenlign alle 64 tegn med linjen for filen i checksumlisten. Store og små bogstaver er uden betydning. Ved forskel: hent begge filer igen fra den samme udgivelse.

Skal jeg have en rig?

Til lokal AI, ja: din egen Windows- eller Linux-maskine med ModelRig. Appsene kan også forbindes direkte til valgfri cloud; det kræver konto og adgang hos udbyderen.

Virker Kaliv uden internet?

Lokal brug forbinder appen til riggen over dit netværk. Modeller og øvrige nødvendige filer skal være hentet først. Downloads, opdateringer og cloud kræver internet.

Findes der en macOS- eller Linux-app?

Der er ingen udgivet macOS- eller Linux-klient. Windows- og Android-klienterne er udgivet. Linux understøttes som maskine til ModelRig-serveren.

Kan jeg hente Kaliv VR eller Hub nu?

VR og Hub er under udvikling. VR kan bygges fra kildekoden, men den aktuelle udgivelse har ingen offentlig VR-APK. Hub er endnu ikke en samlet, fysisk godkendt hjemmeopsætning.

Hvad betyder V1-kriterierne?

De fire kriterier handler om den samlede oplevelse: hukommelse ved genstart, fysiske sanser, sammenhæng mellem enheder og stabil drift. Udgivne apps er ikke i sig selv bevis for alle fire.

Hvor ligger mine data?

Samtaler og indstillinger ligger lokalt på klienten. Dokumentindeks og aktiveret serverhukommelse ligger på riggen. Cloud er et tilvalg, som kan sende den aktuelle besked og relevante vedhæftninger eller værktøjsdata til udbyderen.
